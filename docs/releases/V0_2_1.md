# v0.2.1 release notes

`v0.2.1` promotes the Mail + Cliq AI-employee release candidate to the stable release line.

## Highlights

- Mail remains the stable baseline for list/search/get/send/reply/forward, attachment handling, labels, filters, folders, aliases, and metadata workflows.
- Cliq is release-ready for the AI-employee core: channels/chats, messages/context/watch-context/watch-act, reactions/status reactions, threads, scheduled messages, bots, app catalog/governance, org-directory, and capability probes are exposed behind machine-safe JSON surfaces.
- External Zoho-side limitations remain explicitly deferred: repeated `not_supported`, missing-scope, `inactive_appaccount_user`, and missing CRM-org access outcomes are capability-gated and do not block the stable release.
- The OpenClaw-facing Lane 3 docs now include deterministic update flow, GitHub issue intake guidance, command module maps, and the planned native Cliq channel v0.4 development guide.
- Cliq command implementations have been split by API surface so AI agents can read and modify smaller modules without losing command/help/JSON parity.
